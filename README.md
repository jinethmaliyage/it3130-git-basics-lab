# IT3130 Git Basics Lab

## Purpose

This repository demonstrates a basic Git workflow for IT3130.

## Files

- HelloWorld.html - a small web page used to practise version control
- README.md - project documentation

## Commands practised

git init, git status, git add, git diff, git commit, git log, git remote, git push


## What I learned

Staging lets me choose exactly which changes go into the next commit, so it's a separate step from committing — I can review with git diff --staged before making it permanent.
Each commit captures a snapshot of the project at that point along with a message, so I can track exactly what changed and why over time.
The remote named origin links my local repository to the copy on GitHub, and git push sends my commits there so others (and I) can access the same history from anywhere.
